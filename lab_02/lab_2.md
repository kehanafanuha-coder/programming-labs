Краткие теоретические сведения
Условный оператор if-elif-else: используется для проверки логических условий и ветвления алгоритма. Конструкция elif позволяет связывать несколько последовательных проверок без добавления лишней вложенности отступов. Блок else выполняется, если ни одно из условий не подтвердилось. Обязательным синтаксическим правилом является использование двоеточия (:) и строгое соблюдение отступов (4 пробела).

Цикл while: выполняет блок выражений до тех пор, пока проверяемое условие истинно (True). Для экстренного выхода из цикла применяется оператор break, а для перехода к следующей итерации — continue. При естественном завершении цикла выполняются команды из необязательного блока else.

Цикл for..in и функция range(): осуществляет перебор элементов последовательности (списков, строк или диапазонов). Встроенная функция range(start, stop, step) генерирует арифметическую прогрессию чисел, не включая верхнюю границу stop.

Пользовательские функции (def): представляют собой многократно используемые блоки кода с собственным именем. Функция объявляется с помощью ключевого слова def, принимает параметры и возвращает результаты вычислений оператором return. Строки документации (docstrings в тройных кавычках) размещаются сразу после заголовка функции для описания её назначения.

Задание (вариант 5)
Написать скрипт, моделирующий подачу жидкости в резервуар порциями с использованием пользовательской функции. Функция должна принимать максимальный объём резервуара и объём одной порции, накапливать объём в цикле while, останавливаться при достижении 95 % от максимального объёма (оператор break) и возвращать итоговый объём и количество импульсов насоса. Результат выводить с округлением вещественной части до 2 знаков после запятой. Предусмотреть защиту от бесконечного цикла.

Код:
def fill_tank_simulation(v_max, v_inc):
    """
    Моделирует подачу жидкости в резервуар порциями.
    Возвращает итоговый объем и количество импульсов насоса.
    """
    current_volume = 0.0
    pulses_count = 0
    limit_volume = v_max * 0.95

    print(f"--- Запуск симуляции заполнения (Макс. объем: {v_max} л, Порция: {v_inc} л) ---")

    while True:
        # Защита от бесконечного цикла, если порция больше объема резервуара
        if pulses_count > 10000:
            print("Симуляция прервана: превышен лимит импульсов.")
            break

        pulses_count += 1

        # Проверяем, не превысит ли следующая порция 95% объема
        if current_volume + v_inc >= limit_volume:
            # Наливаем ровно до 95% (последняя неполная порция)
            current_volume = limit_volume
            print(f"Достигнуто 95% объема. Цикл завершен по break.")
            break
        else:
            current_volume += v_inc
            print(f"Импульс {pulses_count}: налито {current_volume:.2f} л.")

    return current_volume, pulses_count


# --- Блок тестирования и разбора результатов ---

print(f"\nРезультат: Итоговый объем = {total_vol:.2f} л, Количество импульсов = {total_pulses}")
